FORJA DE PERGAMINHOS

Programa de PDF com cara de RPG que roda só no seu computador. Seus arquivos não vão para a internet e não tem limite de uso.

ONDE BAIXAR

Na página de downloads do projeto no GitHub (Releases) ficam dois arquivos:

Instalar-Forja-de-Pergaminhos.exe é a versão completa, para instalar do zero.
Atualizar-Forja-de-Pergaminhos.exe traz só o que mudou e serve para quem já tem a Forja instalada.

Na primeira vez o Windows pode mostrar "O Windows protegeu o computador". Clique em "Mais informações" e depois em "Executar assim mesmo".

PROGRAMAS EXTRAS (só para algumas ferramentas)

Word, Excel e PowerPoint para PDF usam o Microsoft Office do computador. Sem Office, instale o LibreOffice (gratuito, libreoffice.org).
PDF para PDF/A precisa do Ghostscript (gratuito, ghostscript.com/releases).
Traduzir PDF usa internet, porque manda o texto para o Google Tradutor.
